Stimgen v2

History

Pick an earlier piece to build a protocol. Everything before it is sent to the model in order, with its reflections.
Context files
pdf, docx, txt and md. Reference is background material like a manual or a book. Example is a piece whose style you want matched. Tick the ones to send with the next write.
prompt.py
Any prompt file works. It looks for SYSTEM_PROMPT or PROMPT, then build_user_prompt(). Repo files work as is. If the file has a validate() function it is run on the result.
mix.py
Any mix file works. Needs a mix(voice_path, music_path, out_path) function. Repo files work as is. Empty uses a plain default mix.
Mix settings
Leave a box empty to let the mix file decide. Music gain maps to music_premix_gain_db, voice level to voice_target_lufs. If the mix file has no such argument the gain is applied to the input file instead and the run log says so. Sync mode and profile only reach mix files that declare them.
